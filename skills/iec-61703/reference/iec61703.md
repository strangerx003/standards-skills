# IEC 61703:2016 (Edition 2.0) — Mathematical expressions for reliability, availability, maintainability and maintenance support terms

Source text: `IEC61703.txt` (English edition pp. 1–98; pp. 100+ are the duplicative French edition). Committee: IEC TC 56 (Dependability). To be used jointly with **IEC 60050-192:2015** (vocabulary), referenced by term numbers like [192-05-06].

---

## 1. Scope and document structure

**Scope.** Provides mathematical expressions for selected reliability, availability, maintainability and maintenance-support measures defined in IEC 60050-192:2015, plus some additional terms. Items are split into:
- **Systems** (made of several individual items) — modelled by **state-transition models** and **Markovian models** (constant transition rates).
- **Individual items**, each with two states:
  - **non-repairable** [192-01-12] — one random variable, the time to failure;
  - **repairable** [192-01-11]:
    - (i) **zero (negligible) time to restoration** — *simple (ordinary) renewal process*;
    - (ii) **non-zero time to restoration** — *simple (ordinary) alternating renewal process*.

Focused on hardware but many terms apply to items containing software. General assumptions throughout: item as good as new at t=0 (`R(0) = A(0) = 1`); continuous positive r.v.s with densities and finite expectations; up/downtimes i.i.d. and independent; repairs restore to as good as new; **no preventive maintenance / planned function-preventing actions**; latent faults ignored.

**Structure**
- §5 General models and assumptions (up/down time constituents; state-transition approach; COI vs IOI).
- §6.1 Systems (availability, reliability, Vesely failure rate, failure intensity/density, restoration expressions, production availability, MTTFF, METBF).
- §6.2 Non-repairable individual items.
- §6.3 Repairable items, zero time to restoration.
- §6.4 Repairable items, non-zero time to restoration (availability family, maintainability, repair rate, times/delays).
- **Annex A** (informative): performance aspects/descriptors diagram (relationships between aspects, random variables, probabilistic descriptors, modifiers — no direct column relationships).
- **Annex B** (informative): Table B.1 (relations among F, f, R, λ); Table B.2 (distributions of time to failure: exponential, Weibull, Gamma, Erlang, Rayleigh, lognormal); Table B.3 (distributions of repair time: deterministic, exponential, lognormal).
- **Annex C** (informative): Table C.1 comparing dependability measures for COIs with constant λ and µ_R across the three item classes.
- §2 Normative refs: IEC 60050-192:2015; ISO 3534-1:2006. §3 Terms/definitions (7 new terms: restoration intensity, repair rate modification, METBF, up-time distribution, up-time hazard rate, generalized λ(t), Vesely λ_V, z(t), COI, IOI). §4 Glossary of symbols/acronyms.

Key changes vs Edition 1 (2001): self-contained; individual items vs systems split; Vesely (conditional) failure intensity introduced; state-transition/Markov models introduced; availability generalized to *production availability*; illustrative curves added.

## 2. Basic definitions and their exact formulas (Clauses 3–4)

### 2.1 Time constituents (Figures 1–3)

- **Up time** [192-02-02] = operating time [192-02-05] + non-operating time (idle time [192-02-15] + standby time [192-02-13]); **MUT** [192-08-09] = mean up time. Enabled time = operating time (COI); = operating + standby + idle (IOI).
- **Down time** [192-02-21] = corrective maintenance time [192-07-07] split as:
  - **time to restoration** [192-07-06] = fault detection time + administrative delay [192-07-12] + logistic delay [192-07-13] + **active corrective maintenance time** [192-07-10] (= technical delay [192-07-15] + repair time [192-07-19], split further into fault localization, fault correction, function checkout).
  - Mean values: **MTTR** = MFDT + MAD + MLD + MACMT, and

$$\text{MTTR} = \text{MFDT} + \text{MAD} + \text{MLD} + \text{MTD} + \text{MRT}$$

  - **MDT** [192-08-10] (mean down time) = MTTR under this standard's no-PM assumption.
- **Failure times (Fig. 3):** for a repairable item, operating time to first failure → **MTTFF** [192-05-12]; operating time between failures → **MTBF/MOTBF** [192-05-13]; mean of all operating times to failure → **MTTF** [192-05-11]; **(elapsed) time between failures** → **METBF** (elapsed, includes down time).

**Time-between-failures vs operating-time-between-failures (§6.1.4, Fig. 28):**

$$\text{METBF} = \text{MUT} + \text{MDT}$$

and, with no preventive maintenance (MDT = MTTR):

$$\text{METBF} = \text{MUT} + \text{MTTR}; \qquad \text{(COI)}\quad \text{METBF} = \text{MTTF} + \text{MTTR}$$

(MTBF must not be used for mean time between failures; IEC 60050-192 reserves MTBF/MOTBF for mean *operating* time between failures.)

### 2.2 Intensity/rate definitions (§3)

| Symbol | Name | Defining formula / condition |
|---|---|---|
| $\nu(t)$ | Instantaneous restoration intensity (restoration frequency) §3.1 | $\nu(t)=\lim_{\Delta t\to 0^+}\dfrac{E[N_R(t+\Delta t)-N_R(t)]}{\Delta t}\Big|\ \text{as good as new at }0$ ($N_R$ = number of restorations in [0,t]); analogous to failure intensity z(t) |
| $\mu(t)$ | Instantaneous repair rate §3.2 | $\mu(t)=\lim_{\Delta t\to 0^+}\dfrac{[1-G(t+\Delta t)]-[1-G(t)]}{(1-G(t))\,\Delta t}=\dfrac{g(t)}{1-G(t)}$ — condition: **repair started at t=0**; analogous to failure rate λ(t) |
| METBF §3.3 | Mean (elapsed) time between failures | $E[\text{time between successive failures}]$ |
| $F_U(t)$ | Up-time distribution function §3.4 | $F_U(t)=1-\exp\!\left(-\int_0^t \lambda_U(x)\,dx\right)$; if up times exponential: $F_U(t)=1-e^{-t/\text{MUT}}$, $\lambda_U=1/\text{MUT}$; for COIs $F_U(t)=F(t)$ |
| $\lambda_U(t)$ | Up-time hazard rate §3.5 | $\lambda_U(t)=\lim_{\Delta t\to 0}\dfrac{F_U(t+\Delta t)-F_U(t)}{(1-F_U(t))\Delta t}=\dfrac{f_U(t)}{1-F_U(t)}$; for COIs $\lambda_U(t)=\lambda(t)$ |
| $\lambda(t)$ | Instantaneous failure rate [192-05-06] §3.6 | $\lambda(t)=\lim_{\Delta t\to 0}\dfrac{F(t+\Delta t)-F(t)}{R(t)\Delta t}=\dfrac{f(t)}{R(t)}$ — condition: item **in up state over [0,t]** (generalized beyond IEC 60050-192's non-repairable restriction); also $\lambda(t)=\lim_{\Delta t\to 0}\frac{E[N(t+\Delta t)-N(t)]}{\Delta t}\big|\text{up state over }[0,t]$ |
| $\lambda_V(t)$ | Conditional failure intensity (**Vesely failure rate**) §3.7 | $\lambda_V(t)=\lim_{\Delta t\to 0}\dfrac{E[N(t+\Delta t)-N(t)]}{\Delta t}\Big|\ \text{up state at }t\ \text{and as good as new at }0$; weaker condition than λ(t); introduced by Vesely 1970 |
| $z(t)$ | Unconditional failure intensity / failure frequency [192-05-08] §3.8 | $z(t)=\lim_{\Delta t\to 0}\dfrac{E[N(t+\Delta t)-N(t)]}{\Delta t}\Big|\ \text{as good as new at }0$; = ROCOF; item may be in any state at t |
| COI §3.9 | Continuously operating item | operating time = enabled time |
| IOI §3.10 | Intermittently operating item | operating time < enabled time |

**Key identities:**

$$\boxed{\lambda_V(t) = \frac{z(t)}{A(t)}}, \qquad \boxed{z(t) = A(t)\,\lambda_V(t)}$$

($A(t)$ = instantaneous availability). Units of all rates/intensities: time⁻¹.

### 2.3 Principal symbols (§4.3 excerpt)

$A$ asymptotic availability; $A(t)$ instantaneous availability; $A(t_1,t_2)$ mean availability; $U$/$U(t)$/$\bar U(t_1,t_2)$ unavailability analogues; $Ast_i(t_1,t_2)$ mean accumulated sojourn time in state i; $F_U, f_U$ up-time cdf/pdf; $G(t)$ repair-time cdf; $g_{ACM}, g_{AD}, g_D, g_{LD}, g_{MA}, g_R$ pdfs of maintenance times/delays/down times/restitution times; $h_n^{CTTF}(t)$ calendar-time-to-nth-failure pdf; $K_A,K_S,K_i$ production capacities; $K(t)$ instantaneous production capacity; $N(t), N_R(t)$ numbers of failures/restorations in [0,t]; $Z(t)=E[N(t)]$ expected number of failures in [0,t]; $V(t_1,t_2)$ mean number of restorations in [t₁,t₂]; $M(t)$ maintainability function; $n_S,n_U,n_D,n_R$ population counts still operational/in up/in down/under repair; $Tbf_\infty(t)$ mean elapsed time between consecutive failures; ρ production per unit time; τ test interval.

**Acronyms:** COI, IOI, MACMT, MAD, MADT(t₁,t₂) (mean accumulated downtime), MAUT(t₁,t₂), MDT, METBF, MFDT, MLD, MMAT, MRT, MOTBF, MTD, MTTF, MTTR, MUT, VRT (repair-time variance $E[\zeta^2]-\text{MRT}^2$).

## 3. State-transition/Markov foundation (§5)

- System example (Fig. 4–5): 2-out-of-3 blocks A plus a perfect standby B; 7 states (up states 1–4, down states 5–7), each state classified **critical/non-critical** by whether it is separated from the other class by exactly one transition.
- **Non-repairable item (Fig. 6–7):** up → (down, absorbing); number of failures ∈ {0,1}, repairs 0.
- **Instantaneous repair (Fig. 8–9):** zero-duration down state; as-good-as-new repair ⇒ **ordinary renewal process**; useful to count failures over intervals (operational time accumulation; calendar-time use is conservative).
- **Non-instantaneous repair (Fig. 10–11):** up/down alternation ⇒ **alternating renewal process**.
- **IOI handling (Fig. 12–13):** reliability expressions of COI remain valid for IOI **if the item cannot fail in idle/standby states**, using the *equivalent operating time* (epochs of enabled time re-mapped to a 0,1,2,… clock); otherwise general stochastic processes are needed.

## 4. Systems — Markov expressions (§6.1)

Reference model (Fig. 14–15): two repairable redundant components A, B with constant failure rates λ_a, λ_b and repair rates µ_a, µ_b; states 1 (AUBu), 2 (A down, B up — critical), 3 (B down, A up — critical), 4 (both down — single critical down state); λ_a: 1→3, λ_a: 2→4, λ_b: 1→2, λ_b: 3→4; µ_b: 2→1, µ_b: 4→3, µ_a: 3→1, µ_a: 4→2.

### 4.1 Instantaneous availability / unavailability (§6.1.2.1)

$$A(t) = P(\text{up state at } t) = \sum_{i\in \text{up}} P_i(t), \qquad U(t) = P(\text{down state at } t), \qquad A(t) + U(t) = 1$$

For the example: $A(t)=P_1(t)+P_2(t)+P_3(t)$, $U(t)=P_4(t)$. ("Availability Markov graph".)

### 4.2 Steady-state / asymptotic values (§6.1.2.2)

$$A = \lim_{t\to\infty} A(t), \qquad U = \lim_{t\to\infty} U(t)$$

Exist for Markov models; $A = P_1+P_2+P_3$, $U = P_4$ (asymptotic state probabilities). Steady state is a property of the process (detailed balance), not of the item; asymptotic probabilities also equal the long-run proportions of time in states. In practice steady state is reached after roughly **2–3 × the largest MTTR** of components (when MTTR ≪ MTTF).

### 4.3 Mean availability / unavailability (§6.1.2.3)

$$A(t_1,t_2) = \frac{1}{t_2-t_1}\int_{t_1}^{t_2} A(t)\,dt = \frac{\sum_{i\in\text{up}} Ast_i(t_1,t_2)}{t_2-t_1}, \qquad Ast_i(t_1,t_2)=\int_{t_1}^{t_2}P_i(t)\,dt$$

$$U(t_1,t_2) = \frac{1}{t_2-t_1}\int_{t_1}^{t_2}U(t)\,dt = \frac{\sum_{j\in\text{down}}Ast_j(t_1,t_2)}{t_2-t_1}$$

(NOTE: mean unavailability = **PFDavg** in functional-safety contexts, IEC 61508/61511.) For the example: $A(t_1,t_2)=[Ast_1+Ast_2+Ast_3]/(t_2-t_1)$; $U(t_1,t_2)=Ast_4/(t_2-t_1)$.

**Asymptotic mean values (existence ⇒ limits equal steady state):**

$$\lim_{t_2\to\infty}A(t_1,t_2) = \lim_{t_1\to\infty}A(t_1,t_2) = A, \qquad \lim U(t_1,t_2) = U$$

**Fundamental closed-form relation (asymptotic/steady state):**

$$\boxed{A = \frac{\text{MUT}}{\text{MUT}+\text{MDT}}}, \qquad \boxed{U = \frac{\text{MDT}}{\text{MUT}+\text{MDT}}}$$

(no PM ⇒ MDT = MTTR). These hold even when $A(t),U(t)$ do not converge (e.g. **periodically tested, normally dormant item**, Fig. 19, test interval τ): $A(t)$ is a saw-tooth with no asymptote but

$$A = \lim_{i\to\infty} A(i\tau, (i+1)\tau) = \lim_{t_2\to\infty} A(0,t_2) = \frac{\text{MUT}}{\text{MUT}+\text{MDT}}$$

### 4.4 Production availability (multi-state extension) (§6.1.2.4)

Production system with states i having (nominal) capacities $K_i$, nominal production ρ per unit time:

$$K(t) = \sum_{i=1}^{n} P_i(t)\cdot K_i, \qquad Prod(t) = K(t)\cdot \rho$$

$$Prod(t_1,t_2) = \rho\sum_{i=1}^{n} K_i \, Ast_i(t_1,t_2), \qquad \overline{Prod}(t_1,t_2) = \frac{Prod(t_1,t_2)}{t_2-t_1} = \frac{\sum_i K_i\,Ast_i(t_1,t_2)}{t_2-t_1}$$

Conventional availability = special case $K_i=100\%$ (up states) / $0\%$ (down states), equivalently $A(t)\equiv Prod(t)\equiv K(t)$ when ρ=1. With steady state, mean production → $K(\infty)\rho$. Called **production availability** or **effectiveness**.

### 4.5 Reliability of systems (§6.1.3.1)

Reliability R(t₁,t₂): up state at t₁ **and** never in a down state on [t₁,t₂]. Obtained with a **reliability Markov graph** (down state(s) made absorbing — Fig. 24; "reliability Markov graph"), in two steps:
1. Initial state probabilities $P_i^{av}(t_1)$ from the availability graph;
2. Propagate on the absorbing graph for θ = t₂−t₁:

$$R(t_1,t_2) = P_1^{rel}(\theta)+P_2^{rel}(\theta)+P_3^{rel}(\theta) = \sum_{i\in\text{up}}P_i^{rel}(\theta), \qquad F(t_1,t_2) = P_4^{rel}(\theta), \qquad R(t_1,t_2)+F(t_1,t_2)=1$$

$$R(t) = \sum_{i\in\text{up}}P_i^{rel}(t) = \sum_{i\in\text{up}} P_i^{rel}(0,t), \qquad F(t)=P_4^{rel}(t), \qquad R(t)=R(0,t)$$

$$\lim_{t\to\infty}R(t)=0,\qquad \lim_{t\to\infty}F(t)=1 \quad (\text{absorbing state})$$

For a COI whose graph is a reliability graph, the **fundamental reliability link**:

$$R(t) = \exp\left(-\int_0^t \lambda(x)\,dx\right)$$

Estimator from n items: $\hat R(t) = n_S(t)/n$ ($n_S$ = items failure-free over [0,t]). Renewal point: if as good as new after restoration to perfect state, any restoration instant may serve as t=0.

### 4.6 Mean time to first failure (§6.1.3.2)

$$\text{MTTFF} = \int_0^\infty t\,f(t)\,dt = \int_0^\infty R(t)\,dt$$

Markov/COI form via reliability-graph sojourn times:

$$\text{MTTFF} = \lim_{t\to\infty}\sum_{i\in\text{up}} Ast_i(0,t)$$

(converges faster for unreliable systems; on a reliability graph $Ast_4(0,t)\to\infty$).

### 4.7 Mean failure rate, Vesely rate, failure density, failure intensity (§6.1.4–6.1.6)

**Instantaneous failure rate** (generalized): $\lambda(t)=f(t)/R(t)$; elementarily $\lambda(t)=-dR(t)/R(t)$. From the reliability (absorbing) Markov graph — failure only from **critical up states** to down states:

$$\lambda(t) = \frac{\lambda_a\,P_3^{rel}(t) + \lambda_b\,P_2^{rel}(t)}{P_1^{rel}(t)+P_2^{rel}(t)+P_3^{rel}(t)} \qquad\text{(up state over [0,t] condition)}$$

**Vesely rate** from the availability (non-absorbing) graph:

$$\lambda_V(t) = \frac{\lambda_a\,P_3^{av}(t) + \lambda_b\,P_2^{av}(t)}{P_1^{av}(t)+P_2^{av}(t)+P_3^{av}(t)} = \frac{z(t)}{A(t)} \qquad\text{(up state at }t\text{ only)}$$

**Failure density:** $f(t)\,dt$ = P(first failure in [t, t+dt] | up & as good as new at 0):

$$f(t) = \lambda(t)\,R(t) = \frac{dF(t)}{dt}; \qquad f(t) = \lambda_a P_3^{rel}(t) + \lambda_b P_2^{rel}(t)$$

**Unconditional failure intensity:** $z(t) = A(t)\,\lambda_V(t) = \lambda_a P_3^{av}(t) + \lambda_b P_2^{av}(t)$; also

$$z(t) = \lim_{\Delta t\to 0}\frac{E[N(t+\Delta t)-N(t)]}{\Delta t}, \qquad Z(t) = E[N(t)] = \int_0^t z(t)\,dt, \qquad z(t) = \frac{dZ(t)}{dt}$$

$$z(t_1,t_2)=\frac{1}{t_2-t_1}\int_{t_1}^{t_2}z(t)\,dt, \qquad E[N_{12}] = (t_2-t_1)\,z(t_1,t_2)$$

(NOTE: mean failure frequency = **PFH** in functional-safety contexts.)

**Asymptotic / mean relations:**

$$\lim_{t\to\infty}\frac{Z(t)}{t} = z(\infty), \qquad \lim_{t\to\infty}\frac{Z(t)}{t} = \lim \frac{t}{Tbf_\infty(t)}\Big/1 = \frac{1}{\text{METBF}} \;\Rightarrow\; \boxed{z(\infty) = \frac{1}{\text{METBF}}}$$

**Comparison of λ(t), λ_V(t), z(t), f(t) for Markov models (§6.1.6–6.1.7, Fig. 29–31):**
- Short term: all four numerically close; as t grows, λ(t), λ_V(t), z(t) converge to asymptotic values while f(t) → 0 (item can fail only once).
- $\lambda_V(\infty) \ge \lambda(\infty)$ and $z(\infty) \ge \lambda(\infty)$ for systems of independent repairable components with constant rates; the faster restoration, the sooner and closer the asymptotes (steady state after ≈ 3 × max MTTR).
- **λ_V(∞) and z(∞) are conservative approximations of λ(∞)**; λ_V is much easier to compute — basis of fault-tree (IEC 61025) and RBD (IEC 61078) calculations for repairable components.

**Sequence ("cut-like") approximation for λ(∞) ≈ λ_V(∞) (fast repairs; Fig. 15):** for each sequence perfect state → down state through a critical state (time in it negligible; from it the component is repaired w.p. $\mu/(\mu+\lambda')$ or fails further w.p. $\lambda'/(\mu+\lambda')$), the transition rate is $\lambda\cdot\lambda'/(\mu+\lambda')$. For the example (sequences 1→2→4 and 1→3→4):

$$\lambda(\infty)\approx\lambda_V(\infty)=\frac{\lambda_a\lambda_b}{\mu_a+\lambda_b}+\frac{\lambda_a\lambda_b}{\mu_b+\lambda_a}$$

(Caveat: results do not hold if some components are non-repaired / no restoration from a failed state.)

### 4.8 Restoration expressions (§6.1.8)

**System repair rate** (from single down state 4 in Fig. 15; system in state 4 at t=0):

$$\mu(t) = \mu_a + \mu_b = \mu, \qquad \text{MRT} = \frac{1}{\mu} = \frac{1}{\mu_a+\mu_b}$$

(A system with several critical down states has no single repair rate — concept mainly relevant for individual items.)

**Restoration intensity** (item as good as new at 0): for the example,

$$\nu(t) = (\mu_a+\mu_b)\,P_4^{av}(t); \qquad \text{general: } \nu(t) = \sum_{\text{critical down } j}\sum_i \mu_{ji}(t)\,P_j(t)$$

Mean restoration frequency and number of restorations over [t₁,t₂]:

$$\nu(t_1,t_2)=\frac{1}{t_2-t_1}\int_{t_1}^{t_2}\nu(t)\,dt, \qquad V(t_1,t_2)=E[N_R(t_1,t_2)] = \int_{t_1}^{t_2}\nu(t)\,dt$$

**Mean time to restoration** from accumulated down-state sojourn times:

$$\text{MTTR} = \frac{\sum_{j\in\text{down}} Ast_j(t_1,t_2)}{V(t_1,t_2)}; \qquad \text{example: } \text{MTTR} = \frac{1}{\mu_a+\mu_b}$$

(no PM ⇒ MDT = MTTR.)

## 5. Non-repairable individual items (§6.2) — COI only

Here $A(t)\equiv R(t)$ (reliability and availability merged) and $A = 0$.

**Reliability [192-05-05]:**

$$R(t)=R(0,t)=\exp\!\left(-\int_0^t \lambda(x)\,dx\right), \qquad R(t) = \int_t^\infty f(x)\,dx = 1-F(t), \qquad F(t)=\int_0^t f(x)\,dx$$

$$R(t_1,t_2)=R(t_2)\ \text{(no repair)}; \qquad \hat R(t) = \frac{n_S(t)}{n}$$

Probability of failure in [t₁,t₂]: $R(t_1)-R(t_2)$.

**Conditional reliability:**

$$R(t, t+x \mid t) = \frac{R(t+x)}{R(t)} = \exp\!\left(-\int_t^{t+x}\lambda(\tau)\,d\tau\right)$$

**Instantaneous failure rate [192-05-06]:**

$$\lambda(t) = \frac{f(t)}{R(t)} = \lim_{\Delta t\to 0}\frac{R(t)-R(t+\Delta t)}{R(t)\,\Delta t}; \qquad \hat\lambda(t)=\frac{n_S(t)-n_S(t+\Delta t)}{n_S(t)\,\Delta t}, \qquad \hat f(t)=\frac{n_S(t)-n_S(t+\Delta t)}{n\,\Delta t}$$

**Mean failure rate [192-05-07]:**

$$\lambda(t_1,t_2) = \frac{1}{t_2-t_1}\int_{t_1}^{t_2}\lambda(t)\,dt = \frac{\ln R(t_1) - \ln R(t_2)}{t_2-t_1}$$

⚠ Use with care: $R(t) = \exp[-\lambda(0,t)\,t]$ formally, but λ(t₁,t₂) "is not a failure rate". For exponential TTF: $\lambda(t_1,t_2)=\lambda$.

**MTTF [192-05-11] (= MTTFF):**

$$\text{MTTF} = \int_0^\infty t f(t)\,dt = \int_0^\infty R(t)\,dt; \qquad \widehat{\text{MTTF}} = \frac{1}{n}\sum_{i=1}^n \text{TTF}_i = \frac{\text{total operating time}}{n}$$

(valid only if all n items failed within the observation period; otherwise use observation duration T for non-failed items — conservative.) With constant rate: $\text{MTTF}=1/\lambda$, $\hat\lambda = n/\sum_i \text{TTF}_i$ (MLE).

**Weibull (2-parameter, scale α, shape β) §6.2.4 d / 6.2.6 d:**

$$R(t)=\exp\big[-(\alpha t)^\beta\big],\quad f(t)=\alpha\beta(\alpha t)^{\beta-1}\exp\big[-(\alpha t)^\beta\big],\quad \lambda(t)=\alpha\beta(\alpha t)^{\beta-1},\quad \text{MTTF}=\frac{1}{\alpha}\,\Gamma\!\left(1+\frac{1}{\beta}\right)$$

$\Gamma(x)=\int_0^\infty t^{x-1}e^{-t}\,dt$. Example: β=2, α=0.5 y⁻¹ ⇒ MTTF = (1/0.5)Γ(3/2) = √π ≈ 1.8 y.

## 6. Repairable items with zero time to restoration (§6.3) — renewal process (COI; some expressions also valid for IOI as stated)

Item repaired instantly to as good as new ⇒ ordinary renewal process with renewal density = z(t). Since always up:

$$A(t) \equiv 1,\quad A(t_1,t_2)\equiv 1,\quad A\equiv 1 \quad \forall t$$

**Interval reliability [192-05-05] (§6.3.2):**

$$R(t_1,t_2) = R(t_2) + \int_0^{t_1} z(t)\,R(t_2-t)\,dt$$

(two cases: no failure until t₂; or last failure+repair at t < t₁ then survival on [t, t₂]). Estimator: $\hat R(t_1,t_2) = n_S(t_1,t_2)/n$. **Asymptotic interval reliability** (key renewal theorem):

$$\boxed{\lim_{t\to\infty} R(t,t+x) = \frac{1}{\text{MTTF}}\int_x^\infty R(s)\,ds} \qquad\text{(never confuse with } R(\infty)=0\text{)}$$

Exponential up times: $R(t_1,t_2)=e^{-\lambda(t_2-t_1)}$ ; asymptotic interval reliability $=e^{-\lambda x}$.

**Renewal machinery (§6.3.3).** With $\Theta_n(t)=\sum_{i=1}^n \tau_{U,i}$ (time to nth failure), and $h_n^{CTTF}(t) = f_U^{*n}(t)$ (n-fold convolution of the up-time pdf $f_U$):

$$h_1^{CTTF}(t) = f_U(t), \qquad h_n^{CTTF}(t) = \int_0^t h_{n-1}^{CTTF}(x)\,f_U(t-x)\,dx,\quad n>1$$

$$z(t) = \sum_{n=1}^{\infty} h_n^{CTTF}(t)$$

**Renewal equation for z(t):**

$$\boxed{z(t) = f_U(t) + \int_0^t z(s)\,f_U(t-s)\,ds} \qquad\text{(linear Volterra eq.; solve numerically)}$$

Estimators: $\hat z(t) = n_F(t,t+\Delta t)/(n\,\Delta t)$; $\hat z(t_1,t_2)=n_F(t_1,t_2)/(n\,(t_2-t_1))$. Exponential up times: $z(t)=A(t)\lambda_U = \lambda_U$ (COI: $=\lambda$).

**Asymptotic failure intensity [192-05-10] (§6.3.4):**

$$\boxed{z(\infty) = \lim_{t\to\infty} z(t) = \frac{1}{\text{MUT}}} \quad \big(=1/\lambda_U\big)$$

(from elementary renewal theorem $\lim E[N(t)]/t = 1/\text{MUT}$ and $\lim Z(t)/t = z(\infty)$; existence conditions: MUT < ∞ and $f_U$ bounded → 0 as t→∞).

**Mean failure intensity [192-05-09] (§6.3.5):**

$$z(t_1,t_2) = \frac{1}{t_2-t_1}\int_{t_1}^{t_2}z(t)dt = \frac{E[N(t_1,t_2)]}{t_2-t_1}; \qquad \boxed{\lim_{t\to\infty}z(t,t+x)=\frac{1}{\text{METBF}}=\frac{1}{\text{MUT}}}\ (\text{Blackwell's theorem})$$

**METBF/mutual identities (§6.3.6):** MDT = 0 ⇒ METBF = MUT $=\int_0^\infty t f_U(t)dt$. For a COI: METBF = MTTF = MOTBF = MUT. (If function-preventing preventive actions exist, METBF > MUT.) Exponential: METBF = 1/λ_U.

**MTTF/MOTBF (§6.3.7–6.3.8):** as-good-as-new ⇒ MTTF = MTTFF = MOTBF $=\int_0^\infty t f(t)dt$; operational-time estimate $\widehat{\text{MTTF}}=\text{total operating time}/k_F$. Exponential: MTTF = MOTBF = 1/λ.

## 7. Repairable items with non-zero time to restoration (§6.4) — alternating renewal process (COI unless stated)

Up times $\tau_{U,i}$ (pdf $f_U$), times to restoration $\xi_{R,i}$ (pdf $g_R$, cdf $G_R$), independent. Compound pdf:

$$f_{R+U}(t) = \int_0^t g_R(s)\,f_U(t-s)\,ds \qquad (f_{R+U}=f_{U+R})$$

### 7.1 Reliability / interval reliability (§6.4.2)

$$\boxed{R(t_1,t_2) = R(t_2) + \int_0^{t_1} \nu(t)\, R(t_2-t)\,dt}$$

with ν(t) the restoration intensity (renewal point after each repair). Estimator $\hat R(t_1,t_2)=n_S(t_1,t_2)/n$. **Asymptotic interval reliability**:

$$\lim_{t\to\infty} R(t,t+x) = \frac{1}{\text{MTTF}+\text{MTTR}}\int_x^\infty R(s)\,ds$$

Exponential TTF: $R(t_1,t_2) = A(t_1)\,e^{-\lambda(t_2-t_1)}$ (availability at t₁ times memoryless survival).

**Both exponential (λ, µ_R):**

$$\boxed{R(t_1,t_2) = A(t_1)\,e^{-\lambda_R (t_2-t_1)}, \qquad A(t_1) = \frac{\mu_R}{\lambda_R+\mu_R} + \frac{\lambda_R}{\lambda_R+\mu_R}\,e^{-(\lambda_R+\mu_R)\,t_1}}$$

$$\lim_{t\to\infty}R(t,t+x) = \frac{\text{MTTF}}{\text{MTTF}+\text{MTTR}}\,e^{-x/\text{MTTF}} = \frac{\mu_R}{\lambda_R+\mu_R}\,e^{-\lambda_R x}$$

Example (Fig. 35): λ = 2 y⁻¹, µ_R = 10 y⁻¹, x = 0.25 y: R(t,t+¼) drops 0.607 → 0.505.

### 7.2 Failure intensity z(t) (§6.4.3)

With $\Theta_n = \tau_{U,1}+\xi_{R,1}+\tau_{U,2}+\cdots+\tau_{U,n}$, pdf $h_n^{CTTF}(t) = f_U^{*n}{}_{R+U}^{\ *(\,n-1\,)}(t)$; recursions:

$$h_1^{CTTF}(t)=f_U(t), \qquad h_n^{CTTF}(t)=\int_0^t h_{n-1}^{CTTF}(x)\,f_{R+U}(t-x)\,dx,\quad n>1; \qquad z(t)=\sum_{n=1}^{\infty}h_n^{CTTF}(t)$$

**Coupled Volterra system for z(t) and ν(t):**

$$\boxed{z(t) = f_U(t) + \int_0^t \nu(s)\,f_U(t-s)\,ds} \qquad \boxed{\nu(t) = \int_0^t z(s)\,g_R(t-s)\,ds}$$

Estimators as in §6.3 but with calendar time (up+down). Exponential up times: $z(t) = A(t)\,\lambda_U$ ($\lambda_U = \lambda$ for COI).

**Both exponential:**

$$\boxed{z(t) = \frac{\lambda_U\lambda_R}{\lambda_U+\mu_R}\left[1 - e^{-(\lambda_U+\mu_R)t}\right]}$$

Example (Fig. 37): λ=2, µ_R=10 ⇒ z(∞) = 20/12 ≈ 1.667 y⁻¹.

### 7.3 Asymptotic and mean failure intensity (§6.4.4–6.4.5)

$$z(\infty) = \lim z(t) = \frac{1}{\text{METBF}} = \boxed{\frac{1}{\text{MUT}+\text{MDT}} = \frac{1}{\text{MUT}+\text{MTTR}}} \qquad\text{(elementary + renewal density theorems)}$$

existence: MUT < ∞, MTTR < ∞, and at least one of $f_U, g_R$ bounded → 0. Exponential: $z(\infty) = A\,\lambda_U = \dfrac{\lambda_U\mu_R}{\lambda_U+\mu_R}$.

Mean failure intensity: $z(t_1,t_2) = \frac{1}{t_2-t_1}\int_{t_1}^{t_2} z(t)dt$; $\hat z = n_F(t_1,t_2)/(n(t_2-t_1))$; asymptote $1/\text{METBF}$. Exponential up times: $z(t_1,t_2)=A(t_1,t_2)\,\lambda_U$. Both exponential:

$$z(t_1,t_2) = \frac{\lambda_U\lambda_R}{\lambda_U+\mu_R}\left[1 - \frac{e^{-(\lambda_U+\mu_R)t_1} - e^{-(\lambda_U+\mu_R)t_2}}{(\lambda_U+\mu_R)(t_2-t_1)}\right] = A(t_1,t_2)\,\lambda_U$$

### 7.4 MOTBF / METBF (§6.4.7–6.4.8)

- **MOTBF = MTTF** (operating time between failures unaffected by downtime; as-good-as-new). Exponential: 1/λ. Example: λ=2 y⁻¹ ⇒ 0.5 y = 4380 h.
- **METBF = MUT + MTTR** $=\int_0^\infty t f_U(t)dt + \int_0^\infty t\,g_R(t)dt$; $\widehat{\text{METBF}}=$ total observation (calendar) time$/k_F$; COI: METBF = MTTF + MTTR. Both exponential: $\text{METBF} = \dfrac{1}{\lambda_R}+\dfrac{1}{\mu_R} = \dfrac{\lambda_R+\mu_R}{\lambda_R\mu_R}$. Example: λ=2, µ_R=10 ⇒ 0.6 y = 5256 h. (If preventive actions occur: METBF = MUT + MDT still valid.)

### 7.5 Availability A(t) (§6.4.9)

**General (both cases of Fig. 39: never failed; or last restoration at x < t and up since):**

$$\boxed{A(t) = R(t) + \int_0^t \nu(x)\,R(t-x)\,dx = 1-F_U(t) + \int_0^t (1-F_U(t-x))\,\nu(x)\,dx}$$

**Renewal-type integral equation** (numerical solution):

$$A(t) = 1-F_U(t) + \int_0^t A(s)\,f_{R+U}(t-s)\,ds$$

Estimator: $\hat A(t)=n_U\{t\}/n$ ($n_U\{t\}$ = items in up state at t).

**Both exponential (Markov or Laplace):**

$$\boxed{A(t) = \frac{\mu_R}{\lambda_U+\mu_R} + \frac{\lambda_U}{\lambda_U+\mu_R}\,e^{-(\lambda_U+\mu_R)t}}$$

Example (Fig. 40): λ=2, µ_R=10: A(0)=1, A(∞)=10/12≈0.833.

### 7.6 Unavailability U(t) (§6.4.10)

Item down at t ⇔ a failure occurred at x and restoration incomplete over [x,t]:

$$\boxed{U(t) = 1 - A(t) = \int_0^t (1-G_R(t-x))\,z(x)\,dx}$$

Estimator: $\hat U(t) = n_D\{t\}/n$. Both exponential:

$$U(t) = \frac{\lambda_U}{\lambda_U+\mu_R}\left[1 - e^{-(\lambda_U+\mu_R)t}\right], \qquad U = \frac{\lambda_U}{\lambda_U+\mu_R}$$

Example (Fig. 42): U(∞) = 2/12 ≈ 0.167.

### 7.7 Mean availability / mean unavailability (§6.4.11–6.4.12)

$$A(t_1,t_2) = \frac{1}{t_2-t_1}\int_{t_1}^{t_2} A(t)dt; \qquad \text{MAUT}(t_1,t_2) = (t_2-t_1)\,A(t_1,t_2); \qquad \hat A(t_1,t_2) = \frac{\text{total up time}}{n\,(t_2-t_1)}$$

$$U(t_1,t_2) = \frac{1}{t_2-t_1}\int_{t_1}^{t_2}U(t)dt = 1 - A(t_1,t_2); \qquad \text{MADT}(t_1,t_2) = (t_2-t_1)\,U(t_1,t_2); \qquad \hat U(t_1,t_2) = \frac{\text{total down time}}{n\,(t_2-t_1)}$$

$\widehat{\text{MAUT}} = $ total up time$/n$; $\widehat{\text{MADT}} = $ total down time$/n$. Asymptotic values: $A = \text{MUT}/(\text{MUT}+\text{MTTR})$, $U = \text{MTTR}/(\text{MUT}+\text{MTTR})$.

**Both exponential:**

$$A(t_1,t_2) = \frac{\mu_R}{\lambda_U+\mu_R} + \frac{\lambda_U}{(\lambda_U+\mu_R)^2}\cdot\frac{e^{-(\lambda_U+\mu_R)t_1} - e^{-(\lambda_U+\mu_R)t_2}}{t_2-t_1} = \frac{z(t_1,t_2)}{\lambda_U}$$

$$U(t_1,t_2) = \frac{\lambda_U}{\lambda_U+\mu_R} - \frac{\lambda_U}{(\lambda_U+\mu_R)^2}\cdot\frac{e^{-(\lambda_U+\mu_R)t_1} - e^{-(\lambda_U+\mu_R)t_2}}{t_2-t_1} = 1 - \frac{z(t_1,t_2)}{\lambda_U}$$

Worked example (Fig. 43–44, λ=2, µ_R=10): MAUT(0,1) = (¼)[A(0,¼)+A(¼,½)+A(½,¾)+A(¾,1)] = (0.887+0.8365+0.8330+0.8335)/4 = 0.847 y = 7424 h; MADT(0,1) = (0.112+0.1645+0.1660+0.1665)/4 = 0.152 y = 1335 h.

### 7.8 Asymptotic availability / unavailability (§6.4.13–6.4.14)

$$A = \lim_{t\to\infty}A(t) = \frac{\text{MUT}}{\text{MUT}+\text{MDT}} = \frac{\text{MUT}}{\text{MUT}+\text{MTTR}}; \qquad A = \frac{\text{MTTF}}{\text{MTTF}+\text{MTTR}}\ \text{(COI)}; \qquad A = \frac{\mu_R}{\lambda_U+\mu_R}$$

$$U = \lim_{t\to\infty}U(t) = \frac{\text{MDT}}{\text{MUT}+\text{MDT}} = \frac{\text{MTTR}}{\text{MUT}+\text{MTTR}} = 1-A; \qquad U = \frac{\text{MTTR}}{\text{MTTF}+\text{MTTR}}\ \text{(COI)}; \qquad U = \frac{\lambda_U}{\lambda_U+\mu_R}$$

### 7.9 MUT (§6.4.15)

$$\text{MUT} = \int_0^\infty t\,f_U(t)\,dt = \int_0^\infty (1-F_U(t))\,dt; \qquad \widehat{\text{MUT}} = \frac{\text{total up time}}{k_U}$$

COI without PM: MUT = MTTF (with function-preventing PM: usually MUT < MTTF, relation complex). Exponential up times: MUT = 1/λ_U.

**IOI worked example (Fig. 45–46):** item must operate on [n(X+Y), n(X+Y)+X] (failure rate λ there), failure-free idle on [n(X+Y)+X, (n+1)(X+Y)]; repairs as good as new. Up-time hazard rate:

$$\lambda_U(t) = \begin{cases} \lambda, & t\in[n\,(X+Y),\ n(X+Y)+X)\\ 0, & t\in[n(X+Y)+X,\ (n+1)(X+Y))\end{cases},\quad n=0,1,2,\dots$$

$$F_U(t) = \begin{cases} 1-\exp(-\lambda\,(t-nX)), & t\in[n(X+Y),\,n(X+Y)+X)\\ 1-\exp(-\lambda\,(n+1)X), & t\in[n(X+Y)+X,\,(n+1)(X+Y))\end{cases}$$

$$\text{MUT} = \frac{1}{\lambda} + \frac{Y\,e^{-\lambda X}}{1-e^{-\lambda X}}, \qquad \text{MOTBF} = \frac{1}{\lambda}$$

(the second term is the expected accumulated idle time to failure). Λ=0.01 h⁻¹, X=10 h: MUT = 195 h (Y=10), 290 h (Y=20), 575 h (Y=50), 1051 h (Y=100); MOTBF = 100 h.

### 7.10 MDT (§6.4.16)

$$\text{MDT} = \int_0^\infty t\,g_D(t)\,dt; \qquad \widehat{\text{MDT}} = \frac{\text{total down time}}{k_D}$$

$g_D$ = pdf of down time (includes time to restoration + function-preventing PM times). Exponential down times ($g_D=\mu_D e^{-\mu_D t}$): $\text{MDT}=1/\mu_D$; under this standard's assumptions any down time = time to restoration ⇒ MDT = MTTR, µ_D = µ_R. Example: µ_D = 100 y⁻¹ ⇒ MDT = 0.01 y = 87.6 h.

### 7.11 Maintainability M(t₁,t₂) [192-07-01] (§6.4.17)

Probability of completing a given maintenance action within [t₁,t₂] given it started at 0:

$$M(t_1,t_2) = \int_{t_1}^{t_2} g_{MA}(t)\,dt, \qquad M(t)=M(0,t)=\int_0^t g_{MA}(x)\,dx \ \ (M(0)=0), \qquad M(t_1,t_2) = M(t_2)-M(t_1)$$

$$\text{MMAT} = \int_0^\infty t\,g_{MA}(t)\,dt = \int_0^\infty (1-M(t))\,dt$$

$g_{MA}$ ≠ restoration intensity ν (which conditions on as-good-as-new at 0, not on a started maintenance action). Specialisations: if action = active corrective maintenance: $M=G_{ACM}$, MMAT = MACMT; if action = repair: $M=G$, MMAT = MRT; if action = whole time to restoration: $M=G_R$, MMAT = MTTR. Estimator: $\hat M(t) = m_{MAT}(t)/m$ (number of maintenance action times longer than t, from m observations, $m_{MAT}(0)=m$). Exponential times ($g_{MA}=\mu_{MA}e^{-\mu_{MA}t}$):

$$M(t_1,t_2) = e^{-\mu_{MA}t_1} - e^{-\mu_{MA}t_2}, \qquad M(t) = 1-e^{-\mu_{MA}t}, \qquad \text{MMAT}=1/\mu_{MA}$$

Example (Fig. 47): µ_MA = 1000 y⁻¹ (0.1142 h⁻¹), t₂−t₁ = 16 h: M(0,16h)=0.839, etc.

### 7.12 Repair rate µ(t) [192-07-20] (§6.4.18)

$$\boxed{\mu(t) = \lim_{\Delta t\to 0}\frac{G(t+\Delta t)-G(t)}{(1-G(t))\Delta t} = \frac{g(t)}{1-G(t)}, \qquad G(t) = \int_0^t g(x)\,dx = 1-e^{-\int_0^t\mu(x)dx}}$$

(g excludes technical/logistic/administrative delays; G(0)=0.) Estimators: $\hat\mu(t) = [n_R(t)-n_R(t+\Delta t)]/(n_R(t)\,\Delta t)$, $\hat g(t) = [n_R(t)-n_R(t+\Delta t)]/(n\,\Delta t)$; constant rate: $\hat\mu = n/\sum_i \text{RT}_i$. Exponential repair times: $g=\mu e^{-\mu t}$, $G=1-e^{-\mu t}$, µ(t)=µ, MRT = 1/µ.

**Lognormal repair times** (scale m, shape σ; Table B.2, §6.4.18 e–f):

$$g(t) = \frac{1}{t\,\sigma\sqrt{2\pi}}\,\exp\!\left(-\frac{(\ln t - m)^2}{2\sigma^2}\right), \qquad \mu(t) = \frac{g(t)}{1-G(t)}, \qquad \text{MRT}=e^{m+\sigma^2/2},\quad \text{VRT}=e^{2m+\sigma^2}\left(e^{\sigma^2}-1\right)$$

Parameter inversion from MRT and VRT:

$$\sigma^2 = \ln\!\left(1+\frac{\text{VRT}}{\text{MRT}^2}\right), \qquad m = \ln \text{MRT} - \frac{1}{2}\ln\!\left(1+\frac{\text{VRT}}{\text{MRT}^2}\right)$$

Example: MRT = 1.5 h, VRT = 0.16 h² ⇒ m = 0.37, σ² = 0.069; lognormal µ(t) peaks (~3.95 h⁻¹ at 2 h in Fig. 48) and → 0.

### 7.13 Times related to restoration / delays — maintenance support terms (§6.4.19–6.4.23)

All of the form $X = \int_0^\infty t\,g_X(t)\,dt$ with estimator (total X time)/(count $k_X$) and exponential specialisation $X = 1/\mu_X$:

| Measure | pdf | Structure notes |
|---|---|---|
| **MRT** [192-07-21] | $g(t)$ | $=\int_0^\infty(1-G(t))dt$; **MRT = MACMT − MTD**; purely hands-on repair |
| **MACMT** [192-07-22] | $g_{ACM}$ | active corrective maintenance incl. technical delay; **MACMT = MRT + MTD**; $\mu_{ACM}=1/\text{MACMT}$ if exponential |
| **MTTR** [192-07-23] | $g_R$ | **MTTR = MFDT + MAD + MLD + MACMT** $= \text{MFDT}+\text{MAD}+\text{MLD}+\text{MTD}+\text{MRT}$; exponential: $\mu_R = 1/\text{MTTR}$ |
| **MAD** [192-07-26] | $g_{AD}$ | administrative delay; exponential: 1/µ_AD |
| **MLD** [192-07-27] | $g_{LD}$ | logistic delay; exponential: 1/µ_AD-analogous 1/µ_LD |

Examples given: MTD=5 h + MRT=9 h ⇒ MACMT=14 h; µ_R=100 y⁻¹ ⇒ MTTR=87.6 h; µ=1000 y⁻¹ ⇒ MRT (or MAD, MLD) = 8.76 h.

**Availability composition via MDT:** since MDT contains all these, $A = \text{MUT}/(\text{MUT}+\text{MDT})$ is the standard's availability expression; logistic/administrative delays raise MDT and lower A. (The standard does **not** define inherent/operational/achieved availability variants; only MUT/(MUT+MDT) is given.)
